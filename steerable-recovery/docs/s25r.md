# S25R 40k / P42 22k

Model name: **`s25r_diffusion`**. This is a separate pair from `r8_s25_diffusion`.

Optional [`--standing-hold`](standing-hold.md): press **Y** after recovery settles
to use encoded standing intent. Available for both robot deployment and MuJoCo.
Source: Stanley's `7ccde04d5af824ea7dc023c8cdf6b9ddaeefd806` simulation handoff.

- 50 Hz tracker, 25-tick / 0.5 s horizon, 2.5 Hz replanning.
- Eight DDIM steps per stage, EMA weights, fresh noise each plan, no blending.
- Both consumers use latest-frame depth v3: `[1,1,2,48,64]`, metadata width 36,
  2 m model cap, 250 ms expiry. Tracker histories repeat the measured first state.
- Exact P42/22k tracker, PD gains, action scales and normalization come from the
  new bundle. Never substitute the R8 tracker or its engines.

## MuJoCo first

Run from `/home/osher/hv2`. Choose one; viewer runs until you stop it, with depth
and no video recording. N resamples planner noise from the same saved start.

```bash
.venv/bin/python g1_deploy/steerable-recovery/sim.py --preset prone --model s25r_diffusion --seed random --replan-hz 2.5
.venv/bin/python g1_deploy/steerable-recovery/sim.py --preset supine --model s25r_diffusion --seed random --replan-hz 2.5
```

Presets use TensorRT FP32 and our 0.5 s startup limiter. For the original
PyTorch/TF32 inference and direct training targets, use the full launcher:

```bash
.venv/bin/python g1_deploy/steerable-recovery/sim.py --model s25r_diffusion --backend pytorch --start supine --seed 42 --noise-only --command-limits training --viewer
```

The generic start above differs from the saved preset. Compare backends from the
same start using `--start-state g1_deploy/steerable-recovery/config/multimodal/flat_three/supine.json`
and the same pose, sensor and planner seeds. No additional camera delay is injected.

The actuated launcher enters zero torque: place the robot at rest or supported
before launching. Wait for readiness. A starts from the measured pose; optional
START moves to the saved joints, then A starts the policy. Accepted A starts all
recordings under `logs/real_world/`; every launch has a new folder. A again,
SELECT or Ctrl+C stops; wait for recording finalization. Extra command limiting
lasts the first 0.5 s only. The normal stop duration is 60 s (`--seconds` changes it).

Replay: `python g1_deploy/steerable-recovery/replay.py RUN_NAME` (use `.venv/bin/python`).
Viser is on port 8081; external video, depth and recorded XYZ are included.
Steering support reuses `--route`, but this delivery's reference evaluations are
unguided; those route outcomes and live XYZ are not newly qualified.
