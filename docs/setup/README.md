# Workstation setup

1. [Install](install.md) the matching HV2 and deployment packages.
2. [Connect](network.md) Ethernet and configure the robot subnet/SSH.
3. [Select](configuration.md) the model bundle and robot settings.
4. [Build LiDAR/DLIO](lidar.md) when using motion recording or estimated steering.
5. Follow [recovery deployment](../recovery/deploy.md) or [SONIC](../sonic/joystick.md).

Optional checks: [camera and robot viewers](sensors.md), [Wi-Fi](wifi.md).
